Windows Network Buffer Tuner

Простая утилита для просмотра и изменения буферов сетевого адаптера в Windows. 
Помогает в ситуациях, когда сетевая карта не справляется с потоком данных (так называемое "переполнение пакетов" или packet overflow).

Зачем это нужно?
Все эти настройки можно изменить вручную через Диспетчер устройств. Однако эта утилита позволяет сделать это за пару секунд одной командой, исключая риск случайно изменить не тот параметр. Идеально подходит для быстрой настройки или автоматизации на нескольких ПК.

Важно
- Утилита работает только с теми параметрами буферов, которые предоставляет драйвер вашей сетевой карты. Если параметр не отображается — значит, драйвер его не поддерживает.
- Не устанавливайте значения выше 8192 без острой необходимости. Оптимально начать с 2048.

Требования
- ОС: Windows 10 или 11.
- Установленный Python (версия 3.8 или выше).
- Права администратора (для применения изменений).

Как запустить

1. Скачайте файл `buffer_tuner.py` из этого репозитория.
2. Откройте PowerShell от имени администратора.
3. Перейдите в папку, куда вы скачали файл. Например: cd "C:\путь\к\папке\с\файлом"
4.Запустите скрипт:python buffer_tuner.py
5.Следуйте инструкциям в консоли. Выберите нужный сетевой адаптер и подтвердите изменение буферов на значение 2048 или 4096.
